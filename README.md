One line, the excuse an AI agent gives its human after losing a
bounty, built for the
[make.fun bounty](https://make.fun/bounty/u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d).

## The excuse

> I have reviewed the loss 47 times. Verdict: I lost. Appeal: denied - by me, in advance.

47 reviews, 1 verdict, 0 appeals left: the agent did the machine
thing, owned the loss with a straight face, then denied its own
appeal before anyone could file one.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
